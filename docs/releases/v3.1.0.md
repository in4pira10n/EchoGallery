EchoGallery v3.1.0 让大型资源库与移动端浏览更流畅，并完善媒体兼容性与播放体验。

EchoGallery v3.1.0 brings smoother browsing for large libraries and mobile devices, with improved media compatibility and playback.

## 更新内容

- `Performance` 优化照片墙内存、媒体并发与预取取消，改善手机连续滚动、横竖屏切换和灯箱返回体验。
- `Library` 完善增量扫描、缩略图复用与 SMB 资源库访问；批量工作流支持独立的 EXIF 修复和文件清理选项。
- `Media` 支持 HEIC/HEIF 缩略图与全分辨率 JPEG 预览，完善 EXIF 读取；异常日期或不可读取的媒体记录不再打断搜索、浏览和构建。
- `Playback` 新增 SRT 字幕、音轨切换缓存与选择记忆；移动端统一使用原生音频链路，视频书签支持命名与动画提示。
- `UI` 新增照片墙 `N` 键名称模式、手机相册右滑返回，以及可开关、可分别设置深浅色的页面渐变层；修复登录返回与灯箱标题布局。
- `Update` 本地更新支持目录发现、安装位置管理与构建编号识别，并完善中英文界面文案。

## What's new

- `Performance` Reduce photo-wall memory use, coordinate media loading and cancel stale preloads; improve mobile scrolling, rotation and lightbox returns.
- `Library` Improve incremental scans, thumbnail reuse and SMB access. Batch workflows offer separate EXIF repair and file cleanup options.
- `Media` Add HEIC/HEIF thumbnails and full-resolution JPEG previews with better EXIF support. Invalid dates and unreadable media records no longer interrupt search, browsing or builds.
- `Playback` Add SRT subtitles, cached audio-track switching with remembered selections, native mobile audio, and named video bookmarks with animated hints.
- `UI` Add the photo-wall `N` name mode, swipe-back navigation in phone albums, and optional page gradients with separate light/dark colors. Fix login history and lightbox title sizing.
- `Update` Improve local update discovery, installation management, build identification and Chinese/English interface copy.

## 说明 / Notes

- HEIC/HEIF 预览、视频缩略图与音轨缓存需要支持相应格式的 FFmpeg 和 ffprobe；不会修改原始媒体。
- HEIC/HEIF previews, video thumbnails and audio-track caches require FFmpeg and ffprobe with the relevant codec support. Original media stays unchanged.
