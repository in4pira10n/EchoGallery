# EchoGallery

[English](../README.md) | [简体中文](README.zh-CN.md)

新一代本地相册管理应用。

## 简介

EchoGallery 是一个本地 Web 相册管理应用，适合在自己的电脑或局域网内浏览、管理和分享照片与视频。

它适合以下场景：

- 需要轻量级、本地运行的资源库
- 希望避免依赖云服务，保护个人隐私
- 希望用时间线、相册、个人收藏和回收站管理本地媒体
- 需要通过简单的分享链接与家人或朋友分享部分照片

## 功能

- 时间线浏览
- 大图浏览模式（灯箱）
- 乱序相册
- 按顺序或随机播放幻灯片
- 链接式分享功能（beta）
- 资源库管理
- 便捷换机（`.echogallery` 随资源库目录保存）
- 智能相册
- 个人收藏与回收站
- 视频缩略图刷新

> 视频封面生成依赖 `ffmpeg`。如果未安装 `ffmpeg`，视频文件仍可管理，但可能无法生成视频缩略图。

## 快捷键

### 全局快捷键

- `Alt + 1`：切换到时间线视图
- `Alt + 2`：切换到收藏视图
- `Alt + 3`：切换到乱序相册视图
- `Alt + 4`：切换到相册视图
- `Alt + 5`：切换到回忆视图
- `Alt + 6`：切换到回收站视图
- `Alt + 7`：切换到设置视图

### 大图浏览模式

- `Esc`：关闭大图模式
- `A`：上一张
- `D`：下一张
- `Space`：切换幻灯片播放
- `F`：加入或移除个人收藏
- `Alt + 0`：返回“适应”模式

### 视频播放器快捷键（使用系统播放器时）

- `X`：暂停或播放
- `Z`：后退 5 秒
- `C`：前进 5 秒
- `W`：增大音量
- `S`：减小音量
- `M`：静音
- `F`：全屏
- `Esc`：退出全屏
- 更多快捷键请参考 `ZXCWASD.conf` 文件

## 快速开始

_如果需要生成视频缩略图，请先安装 `ffmpeg`。_

1. 下载 Release
   - 从 GitHub Release 页面下载对应平台的压缩包或可执行文件。
2. 解压并运行
   - macOS / Linux：在终端进入解压后的目录，执行 `./echogallery`。
   - Windows：双击 `echogallery.exe`，或在命令提示符中运行它。
3. 打开浏览器
   - 访问 `http://127.0.0.1:8080`，打开 EchoGallery 初始化页面。
4. 完成首次设置
   - 按页面提示创建管理员账户。
   - 选择或新建资源库文件夹，用于存放照片、视频和应用数据。
5. 导入资源库
   - 在设置中选择照片和视频所在的文件夹作为资源库。
   - 等待应用扫描并导入现有媒体。
6. 开始浏览
   - 进入时间线、大图浏览、相册、收藏或其他页面查看内容。

> 第一次运行时，如果已经存在 `config.json` 和数据库，EchoGallery 会直接进入主界面；否则会自动进入初始化设置页面。

## 安装

### 环境要求

- Go 1.26+
- ffmpeg

### 构建

```bash
git clone https://github.com/in4pira10n/EchoGallery.git
cd EchoGallery
go build -o echogallery .
```

### 运行

```bash
./echogallery
```

第一次运行时，如果没有 `config.json`，会自动启动初始化设置页面，通常访问：

```text
http://127.0.0.1:8080
```

如果要从另一台电脑迁移，可以在初始化页面选择“导入换机配置包”。配置包会恢复账户、权限、个人偏好、头像、品牌资源和快捷键；资源库本身请连同隐藏的 `.echogallery` 目录完整复制。如果磁盘路径发生变化，重启后在资源库恢复页面选择新路径即可。

资源库的数据库、缩略图、播放缓存、回收站、Logo、名称、强调色和稳定 ID 均保存在 `<资源库>/.echogallery/`。设置页“应用配置”可以导出换机配置包；运行时锁、页面会话、旧缓存、旧电脑的全局缓存路径和本地更新路径不会被打包。配置包包含账户和密码哈希，请像保管密码备份一样妥善保管。
